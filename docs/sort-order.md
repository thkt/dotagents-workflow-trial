# 商品一覧の並び順の保存と復元

この文書は現状の記録であり、並び順の仕様の正本は[README の提供する機能](../README.md#提供する機能)の節です。

商品一覧の並び順がどの条件で保存・復元され、保存できないときにどう振る舞うかを示します。「並び順が戻らない」という報告が現在の仕様どおりか不具合かを判断するときに使います。根拠は[trial/public/search.js](../trial/public/search.js)の現在の実装です。

## 選べる並び順

読みの比較には `Intl.Collator("ja")` を使います。並べ替えは元の行の配列から毎回作るため、同じ読みの行は元の相対順を保ちます。検索で行を隠しても行は削除しないため、検索やクリアの後も選んだ並び順が続きます。

「並び順」の選択肢は次の3つです。

| 画面の表示   | 保存する値   | 並び方                                     |
| ------------ | ------------ | ------------------------------------------ |
| 元の順序     | `original`   | `tbody` に書かれた行の順                   |
| 商品名：昇順 | `ascending`  | 各行の `data-reading` の読みを昇順に並べる |
| 商品名：降順 | `descending` | 各行の `data-reading` の読みを降順に並べる |

## 保存と復元

並び順を選ぶと、画面の並びを更新してから、選んだ値を `localStorage` のキー `product-order` に保存します。「元の順序」も保存します。保存は選択を変えたときだけ行い、ページを開いたときには書き込みません。

ページを開くと `product-order` を読み、`original`・`ascending`・`descending` のいずれかならその並び順で表示します。保存するのは並び順だけです。検索語は保存せず、ページを開くたびに検索欄を空にして全件を表示します。

## 保存や読み込みができないとき

保存や読み込みができなくても、画面の選択と検索はそのまま使えます。失敗を知らせる表示はありません。

| 状況                                        | 振る舞い                                                                                                                                   |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 保存値がない                                | 元の順序で始まる                                                                                                                           |
| 保存値が3つの値と完全には一致しない         | 元の順序で始まる                                                                                                                           |
| `localStorage` の取得や読み込みで例外が出る | 元の順序で始まる                                                                                                                           |
| 選択時の保存で例外が出る                    | 画面には選んだ並び順を適用し、検索とクリアを続けられる。保存値は書き換わらないため、次に開くと以前に保存できた値、なければ元の順序で始まる |

## 報告を切り分けるときの確認点

保存先はブラウザーの `localStorage` です。次の場合に並び順が戻らないのは、[README の提供する機能](../README.md#提供する機能)で定めた現在の仕様の範囲です。

- 別の端末、別のブラウザー、別のプロファイル、別のoriginで開いた。
- ブラウザーのデータ削除やプライベート閲覧の終了で保存値が消えた。
- 前回の選択時に保存が失敗していた。

複数のタブは即時には同期しません。各タブは操作中の選択を保ち、次に開いたときに最後に保存できた値を使います。

これらに当てはまらずに復元されない場合は、不具合の可能性があります。保存・復元と失敗時の振る舞いは[trial/tests/product-order-persistence.spec.js](../trial/tests/product-order-persistence.spec.js)で検証しています。このテストは例外をブラウザー内で注入して再現しており、ブラウザー設定で実際に保存を拒否した場合は検証していません。
