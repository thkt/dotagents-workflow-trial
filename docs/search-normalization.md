# 商品検索の入力正規化

商品一覧の検索が、入力をどう整えて商品と比べるかの現状を記録します。検索が一致しないと報告されたときに、現在の仕様どおりか不具合かを判断するために使います。

根拠は[trial/public/search.js](../trial/public/search.js)の `updateSearch` と、検索対象の列を定める[trial/public/index.html](../trial/public/index.html)です。

## 比較の手順

検索欄の入力が変わるたびに、次の順で各行を表示するか決めます。

1. 比較に使う検索語から、前後の空白を除きます。全角空白も除き、語の間の空白は残します。検索欄の表示は入力したままです。
2. 検索語と各セルの文字列を小文字に変え、英字の大文字と小文字を同一視します。
3. 行のいずれかのセル（商品名・商品コード）が検索語を部分文字列として含めば、その行を表示します。含まない行は隠します。

入力が空、または空白だけのときは全件を表示します。表示件数は `全4件中N件を表示` の形で示します。N は表示中の件数です。0 件のときは `該当する商品はありません` を表示します。

| 入力               | 表示する商品           | 理由                                         |
| ------------------ | ---------------------- | -------------------------------------------- |
| `  pEn-001  `      | 黒いペン               | 前後の空白を除き、大文字と小文字を同一視する |
| `note`             | 青いノート、赤いノート | 商品コードの一部に一致する                   |
| `青い`             | 青いノート             | 商品名の一部に一致する                       |
| `ＮＯＴＥ`（全角） | なし                   | 全角英字を半角英字と同一視しない             |

## 現状の制限

全角英数字と半角英数字を同一視しません。商品コードは半角で登録されているため、`ＮＯＴＥ` や `ＭＵＧ－００１` のように全角で入力すると一致しません。全角英数字の同一視は[#145](https://github.com/thkt/dotagents-workflow-trial/issues/145)で扱います。

商品の読みは並び順だけに使い、検索対象に含めません。たとえば `あおいのーと` は「青いノート」に一致しません。

## 検索語の保存とクリア

検索語は保存しません。ページを読み込むと、ブラウザーがフォームの入力を復元した場合も検索欄を空にして、全件を表示します。

「検索をクリア」を押すと検索欄を空にし、全件表示に戻ります。並び順の保存と復元は[READMEの提供する機能](../README.md#提供する機能)を参照してください。
